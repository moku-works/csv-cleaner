# CSV整形・集計ツール
CSVファイルの整形（空白除去・全角半角統一・重複行削除・金額や日付の表記統一）と、グループ別の集計（合計・件数・平均）がブラウザだけでできるツールです。データ入力・リスト作成の補助ツールとして制作しました。

## 改善事例として

**課題**
店舗や担当者ごとに表記がバラバラなCSV（全角・半角の混在、「1,200円」のような金額表記、日付形式の不統一、重複行や空行）が届くたびに、表計算ソフトで手直ししてから集計する必要がありました。

**対応**
ブラウザだけで完結する整形・集計ツールを作りました。ファイルを読み込むと、空白の除去、全角・半角の統一、金額の数値化、日付の統一（YYYY-MM-DD）、重複行・空行の除去をまとめて行い、店舗別などのグループ集計とグラフ表示までできます。データは外部に送信されず、ブラウザ内で処理されます。

**効果（目安と検証結果）**
手作業では30分ほどかかる整形と集計が、読み込みから結果確認まで数分で終わる想定です。検証では、サンプルの売上データ（9行・5列）で重複3件が除去され、店舗別合計（新宿店 4,200円・池袋店 3,840円・渋谷店 2,310円）が手計算と一致することを確認しています。
